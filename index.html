Решение шифров Цезаря

1. Определение ключа шифра Цезаря

а. АПЕЛЬСИН → САЦЬНВЩЮ

Ключ: 2

Обоснование: Каждая буква сдвинута на +2 позиции в алфавите (с учётом кириллицы без «Ё»).

б. АБРИКОС → ЫЬЛГЕЙМ

Ключ: 30 (или эквивалентно -2)

Обоснование: Каждая буква сдвинута на -2 позиции (или +30 при модуле 32).

2. Расшифровка сообщений

а. ФХНЗКЧ

Расшифровано: ШИФРЫ

Ключ: 26 (или -6)

б. ЦЩЕБФ

Расшифровано: ТЕСТЫ

Ключ: 26 (или -6)

3. Шифрование фамилии

Фамилия: АНДРИЯНОВА

Ключ: 10

Зашифровано: КЧНБОТЩЧЖК

Приложение: Код для GitHub (Python)

# caesar_cipher.py

def caesar_cipher(text, shift, decrypt=False):
    alphabet = 'АБВГДЕЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ'
    result = ''
    shift = shift % len(alphabet)
    if decrypt:
        shift = -shift
    for char in text.upper():
        if char in alphabet:
            idx = (alphabet.index(char) + shift) % len(alphabet)
            result += alphabet[idx]
        else:
            result += char
    return result

# Примеры использования:

# 1. Найти ключ по паре открытый/шифротекст
def find_key(plain, cipher):
    alphabet = 'АБВГДЕЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ'
    p0 = alphabet.index(plain[0])
    c0 = alphabet.index(cipher[0])
    return (c0 - p0) % len(alphabet)

print("Ключ для АПЕЛЬСИН → САЦЬНВЩЮ:", find_key("АПЕЛЬСИН", "САЦЬНВЩЮ"))
print("Ключ для АБРИКОС → ЫЬЛГЕЙМ:", find_key("АБРИКОС", "ЫЬЛГЕЙМ"))

# 2. Расшифровка
print("ФХНЗКЧ расшифровано:", caesar_cipher("ФХНЗКЧ", 26, decrypt=True))
print("ЦЩЕБФ расшифровано:", caesar_cipher("ЦЩЕБФ", 26, decrypt=True))

# 3. Шифрование фамилии
surname = "АНДРИЯНОВА"
encrypted = caesar_cipher(surname, 10)
print(f"Фамилия '{surname}' зашифрована как: {encrypted}")
